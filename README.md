# yaella

יאללה + יעל: דפים שאני שולחת לחברים ולרועי. האתר: https://yaelavgil.github.io/yaella/

## סדר הקבצים
- `index.html`: עמוד הבית עם רשימת כל הדפים. כדי להוסיף דף לרשימה מוסיפים רשומה למערך `PAGES`.
- תיקייה אחת לכל נסיעה או נושא. הדף הראשי נמצא ב־`index.html` של התיקייה, עם `og.jpg` (התמונה לתצוגה המקדימה בוואטסאפ) ו־`img/`. תת־נושאים יושבים בתיקיות משנה.

```
elections-2026/        שליף אמת · למה הדמוקרטים (שליף לנייד, לחברים) · 27.10.2026
ostrava-2027/          רובי באוסטרבה · מצטרפים? (הדף הראשי, לחברים) · 6.10.2026
├── map/               הפסטיבל על המפה
└── photos/            הסביבה בתמונות
garden/                איזה עץ זה? · משחקון ניחוש העצים בגינה בהקמה (למשפחה, לאביבה) · 22.10.2026
stepping-stones/       שביל אבני המדרך · מפה אינטראקטיבית לסידור האבנים בחצר (למעצבת) · 18.10.2026
lucy/                  לוסי בת 12 · לוח משותף לבחירת תמונות לסרטון (זמני, הנתונים ב־Firebase) · 13.10.2026
```

תמונות: Wikimedia Commons (הקרדיט מופיע בכל דף) וצילומי מלונות מ־Booking.com.
